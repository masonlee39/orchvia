# Release-readiness ledger

Rebuilt on 2026-09-29 (SPEC-0043 L01). Each gate below has a state, the evidence behind it, and what would close it. Closed means the evidence covers the claim; partial means some of it is covered and the rest is named; open means nothing yet covers it. Implemented behavior is recorded per specification in [the status page](../status.md) and the TDD records.

## Verified runtime versions

- Codex CLI versions verified in CI: 0.153.4, 0.157.1 and 0.158.0.
- Claude Agent SDK versions verified in CI: 0.3.283, and 0.3.274 for usage outside the main loop.
- Every native check uses the real binary against a loopback scripted gateway, with synthetic credentials and no model calls. A weekly workflow runs the same checks with the newest versions on npm and reports them, without changing what is verified (SPEC-0043 A01).

## Reproduce native runtime verification without paid models

Install the pinned development dependencies, including Codex 0.157.1 for the second command (SPEC-0032 B04). The native CI job and the weekly drift workflow run these and the other native smokes. Use a new evidence path for every run; existing evidence is never overwritten.

```sh
node scripts/native-gateway-smoke.mjs claude dist/verification/native-claude-new.json
node scripts/native-gateway-smoke.mjs codex dist/verification/native-codex-new.json /absolute/path/to/codex
```

The process replaces its environment with an isolated home, points model requests at its loopback server, uses synthetic tokens, limits gateway requests and turn duration, and removes its owned test workspaces after saving evidence. The script requires local Unix IPC and loopback permissions. Normal `npm test` invokes no native model endpoint; the separate CI native job explicitly runs this script.

Paid/private-gateway experiments remain separate. `npm run native:prepare -- /absolute/new-plan.json` writes a reviewable one-turn plan without inspecting credentials. Record the exact runtime/model/identity-source label and approved limits before running a real endpoint.
